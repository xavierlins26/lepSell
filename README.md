# Lepsell
> Sistema de caixa e gestão de estoque e de vendas para microemprendedores

## Funcionalidades
- Criar um sistema de caixa próprio 
- Comandar entradas e saídas de produtos do mercado
- Salva saidas de produtos mensais do estoque
- Sistema de ponto de caixas

## Tecnologias
Este projeto foi desenvolvido com:
* HTML e CSS
* Java Script
* Sql
